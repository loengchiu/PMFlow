# Prototype UI 风格基准

本文件把现有系统设计稿转成文字规则，供不能读取图片的执行器使用。

适用范围：

- `/pm-prototype` 生成高保真 HTML 原型。
- `/pm-prototype-review` 检查 UI 是否贴近现有系统。

本文件只约束视觉语言和组件表达，不决定页面应该有哪些业务内容。页面内容仍由 PRD、wireframe、metadata 和 PM 注释决定。

## 1. 整体气质

原型是 B 端中后台系统页面，不是营销页、门户页、炫酷大屏或移动端页面。

目标气质：

- 清爽。
- 规整。
- 信息密度较高。
- 业务优先。
- 少装饰。
- 可评审、可交付、研发容易理解。

页面应该像“交投智慧服务区管理平台”的一个真实模块。

## 2. 页面框架

常见框架：

```text
左侧模块导航 + 顶部一级导航 + 当前页面标题 / tab + 主内容区
```

布局特征：

- 左侧导航固定宽度，约 216px 到 240px。
- 顶部导航高度约 56px 到 66px。
- 内容区背景为浅灰。
- 主体内容使用白色卡片承载。
- 内容区与卡片之间保留 16px 到 24px 间距。
- 页面整体是桌面宽屏布局，优先适配 1440px 到 1920px。

左侧导航：

- 白底。
- 顶部显示平台 logo / 品牌区。
- 一级菜单使用图标 + 文本。
- 当前菜单蓝色背景、白色文字、圆角矩形。
- 展开的二级菜单缩进显示。
- 未选中菜单使用深灰文字。
- 折叠菜单右侧可显示箭头。

顶部导航：

- 白底。
- 横向一级业务域。
- 当前一级业务域蓝色背景、白色文字。
- 未选中一级业务域为深色文字。
- 顶部与内容区之间有浅灰分割线或轻微阴影。

页面标题 / 二级 tab：

- 当前页面可在内容顶部显示短标题或 tab。
- 当前 tab 使用蓝色文字和蓝色下划线。
- tab 区域白底，底部可有轻微阴影或分割线。

## 3. 色彩

主色：

- 蓝色用于当前态、主按钮、tab 下划线、链接、选中菜单。
- 推荐范围：`#1F6FEB`、`#2B73E8`、`#1677FF`。

背景：

- 页面背景：`#F3F6FA`、`#F5F7FA`、`#F7F9FC`。
- 卡片背景：`#FFFFFF`。

文本：

- 一级标题：接近 `#1F2329`。
- 正文：接近 `#333333`。
- 次级说明：接近 `#666666`、`#8A8F99`。
- 表格表头：深蓝灰或深灰。

边框：

- 表格线、输入框线、卡片分割线使用浅灰：`#E5EAF2`、`#E8EDF5`、`#DDE3EC`。

状态色：

- 成功 / 已完成 / 已离场：绿色标签，浅绿底 + 绿色文字。
- 进行中 / 当前在场：蓝色标签，浅蓝底 + 蓝色文字。
- 告警 / 未处理 / 异常：红色或橙色文字 / 标签。
- 导出类操作：橙色描边按钮。

## 4. 字体与间距

字体：

- 使用系统默认中文字体即可。
- 不使用装饰字体。
- 不使用大面积加粗。

字号参考：

- 平台标题：24px 到 28px。
- 页面标题 / 卡片标题：18px 到 22px。
- 表格、表单、正文：14px 到 16px。
- 次级说明：12px 到 14px。
- 指标数字：26px 到 32px。

间距：

- 卡片外间距：16px 到 24px。
- 卡片内边距：16px 到 24px。
- 表单项横向间距：24px 到 48px。
- 表格行高：44px 到 56px。

圆角：

- 卡片和按钮使用小圆角。
- 常见圆角 4px 到 8px。
- 不使用大圆角胶囊式页面容器。

阴影：

- 轻阴影即可。
- 卡片可使用非常弱的投影。
- 不使用强烈悬浮卡片效果。

## 5. 常用组件表达

组件按 PRD 和 wireframe 需要选择，不固定强塞。

### 5.1 指标卡

适用于看板页或列表页上方概览。

表达方式：

- 白色卡片。
- 左侧业务图标，右侧或下方展示指标名称。
- 右侧大数字。
- 单位使用小号灰字。
- 多张指标卡横向排列。

例：

```text
[图标] 今日入场                         3568 辆
[图标] 今日离场                         3568 辆
[图标] 当前在场                         3568 辆
[图标] 两客一危                           68
```

### 5.2 筛选区

适用于列表管理页。

表达方式：

- 白色卡片内上方区域。
- 多列横向排列。
- 标签在左，输入控件在右。
- 输入框、下拉框、日期范围控件宽度规整。
- 查询按钮为蓝色主按钮。
- 重置按钮为普通描边按钮。
- 导出按钮可放右侧，橙色描边。

例：

```text
车牌号：[请输入车牌名称]    时间范围：[请选择时间段]    车辆状态：[请选择]
服务区：[请选择]            车辆类型：[请选择]          [重置] [查询] [导出Excel]
```

### 5.3 表格

适用于列表、明细、记录。

表达方式：

- 表头浅色背景。
- 表格边线细、浅灰。
- 行高适中。
- 操作列靠右或最后一列。
- 链接操作使用蓝色文字。
- 状态使用浅色底标签。
- 多选列使用 checkbox。
- 底部分页靠右。

表格状态标签：

```text
已离场：浅绿底 + 绿色文字
当前在场：浅蓝底 + 蓝色文字
未处理：红色文字或浅红底
```

### 5.4 详情页

适用于查看单据、车辆、资产、审批对象。

表达方式：

- 主体白色大卡片。
- 信息按分组展示。
- 分组标题左侧可有蓝色竖线。
- 图片 / 附件放在分组顶部或左侧。
- 字段采用多列排布，常见三列。
- 记录类信息使用表格或时间线。

分组示例：

```text
车辆信息
进离场信息
停放信息
两客一危
核查记录
处理记录
状态记录
```

### 5.5 配置页

适用于阈值、规则、参数配置。

表达方式：

- 顶部 tab 切换配置类别。
- 主体白色卡片。
- 一行一个配置对象。
- 左侧显示配置对象名称和说明。
- 中间显示开关。
- 右侧显示数字输入、单位、备注输入。
- 底部左侧或右侧放保存按钮。

配置行示例：

```text
危化品运输车    [开关]    [60] 分钟    [春运期间调整为60分钟]
大型货车        [开关]    [120] 分钟   [备注（可选）]
普通货车        [开关]    [60] 分钟    [备注（可选）]
```

### 5.6 tab

适用于同一业务下的多个子视图。

表达方式：

- 白底横向 tab。
- 当前 tab 蓝色文字 + 蓝色下划线。
- tab 文案简短。
- tab 切换不改变一级导航。

### 5.7 图表和监控区

适用于看板、实时监控。

表达方式：

- 图表放在白色卡片内。
- 饼图 / 环形图 / 柱状图可以用简化 SVG、CSS 或静态图表表达。
- 图例放右侧或右上角。
- 视频监控区域可用深色占位区表达。
- 监控通道按钮使用蓝色当前态。

原型不需要真实视频流。

## 6. 页面类型参考

### 6.1 看板 / 监控页

常用布局：

```text
指标卡区
左侧统计表 / 中间图表 / 右侧监控或状态卡
底部趋势图
```

适用场景：

- 实时监控。
- 数据概览。
- 趋势分析。

### 6.2 列表管理页

常用布局：

```text
指标卡区（按需）
筛选区
表格
分页
```

适用场景：

- 数据管理。
- 记录查询。
- 审核列表。
- 台账列表。

### 6.3 详情页

常用布局：

```text
分组信息
图片 / 附件
明细表
处理记录
状态时间线
```

适用场景：

- 车辆详情。
- 单据详情。
- 资产详情。
- 审批详情。

### 6.4 配置页

常用布局：

```text
tab
配置行
保存按钮
```

适用场景：

- 阈值配置。
- 参数配置。
- 规则配置。

## 7. 原型生成边界

生成原型时：

- 先看 PRD 和 wireframe 定义了什么。
- 再选择合适页面类型和组件。
- 最后套用本文件的视觉语言。

不要因为样式基准中出现某组件，就在所有页面都生成该组件。

示例：

- PRD 定义列表页，生成筛选区、表格、分页。
- PRD 定义详情页，生成分组信息、记录、时间线。
- PRD 定义配置页，生成配置行、开关、输入、保存。
- PRD 没有图表，就不为了像看板而加图表。
- PRD 没有视频监控，就不生成视频占位区。

## 8. Review 使用方式

`/pm-prototype-review` 检查 UI 一致性时，以本文件作为文字基准。

通过标准：

- 页面像现有中后台系统。
- 组件选择符合页面类型。
- 表格、筛选、详情、配置、tab、状态标签等表达自然。
- 颜色、间距、字号、按钮层级和现有系统接近。

不通过情况：

- 页面做成营销页、门户页或炫酷大屏。
- 大量使用渐变、装饰插画、大卡片堆叠。
- 字号和间距明显不适合中后台。
- 为了套样式新增 PRD 未定义的业务内容。
