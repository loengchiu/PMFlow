# PRD 动作样例库

本文件为新主链 `/pm-prd` 提供动作写法的目标样例和非目标样例。

## 1. 列表查询页

**适用场景**：带筛选条件的列表页，默认加载、筛选、排序、分页、空状态。

**目标写法**：

```markdown
进入页面后，系统按当前筛选条件（入库状态、发起方式、目标服务区、关键字、申请时间范围）加载入库记录列表，默认按申请时间降序排列，每页 20 条。

列表展示入库申请单编号、入库申请名称、申请服务区、所在区域、发起方式、申请人、目标服务区、入库状态、申请时间、操作入口。无匹配数据时，列表区显示"暂无入库记录"。
```

**非目标写法 A（太空）**：

```markdown
用户可以查看入库记录列表，支持筛选和排序。
```

问题：缺少具体字段、筛选条件、排序规则、分页参数、空状态。

**非目标写法 B（机械填空）**：

```markdown
**列表字段**：入库申请单编号、入库申请名称、申请服务区...
**筛选条件**：入库状态、发起方式...
**排序规则**：申请时间降序
**分页参数**：每页 20 条
**空状态**：暂无入库记录
```

问题：栏目齐全但像配置清单，不像产品规格说明。

**metadata 字段关系**：

```yaml
pages:
  - id: PRD-PAGE-列表
    page_name: 入库申请列表页
    regions:
      - name: 列表区
        fields:
          - field_id: PRD-FIELD-入库申请单编号
            field_name: 入库申请单编号
            usage: 展示
```

## 2. 新增/编辑表单

**适用场景**：弹窗或页面内表单，含字段、校验、提交。

**目标写法**：

```markdown
服务区管理员点击"新增入库"按钮，打开入库申请弹窗，通过物资选择器从资产库选择标准物资，填写存放位置、数量、税后单价、备注后提交。

提交时校验：
- 标准物资不能为空
- 数量必须大于 0，且为整数
- 税后单价必须大于等于 0，保留 2 位小数
- 备注长度不超过 500 个字符

校验通过后，系统按明细逐条计算税后价值：
1. 任一明细税后价值大于 2000 元时，入库状态为"待财务审核"。
2. 全部明细税后价值均不大于 2000 元时，入库状态为"待确认"。

提交成功后弹窗关闭，列表刷新，提示"提交成功"。
```

**非目标写法 A（太空）**：

```markdown
用户点击新增按钮，填写表单后提交。
```

问题：缺少字段、校验规则、状态分支、成功反馈。

**非目标写法 B（机械填空）**：

```markdown
**触发条件**：点击"新增入库"按钮
**表单字段**：标准物资、存放位置、数量、税后单价、备注
**校验规则**：标准物资必填；数量>0整数；税后单价>=0两位小数；备注<=500字
**提交结果**：生成入库申请单
**成功提示**：提交成功
```

问题：固定栏目，信息完整但读起来像字段配置表。

**metadata 字段关系**：

```yaml
pages:
  - id: PRD-PAGE-入库申请
    page_name: 入库申请页
    actions:
      - id: PRD-ACT-新增入库
        name: 新增入库
        fields:
          - field_id: PRD-FIELD-数量
            field_name: 数量
            usage: 编辑
            rule_refs:
              - PRD-RULE-数量大于零
```

## 3. 审批/确认动作

**适用场景**：审批通过、驳回、确认、会签。

**目标写法**：

```markdown
财务审核员在待审核列表中点击"审核"按钮，打开入库申请详情页，查看物资明细和税后价值汇总后，选择"通过"或"驳回"。

选择"通过"时，入库状态变更为"待确认"，系统记录审核人、审核时间和审核意见。

选择"驳回"时，必须填写驳回原因（不超过 500 字），入库状态变更为"已驳回"，系统通知申请人。
```

**非目标写法 A（太空）**：

```markdown
财务审核员审核入库申请，可以通过或驳回。
```

问题：缺少状态变化、审核记录、驳回原因要求、通知机制。

**非目标写法 B（机械填空）**：

```markdown
**审核动作**：通过 / 驳回
**通过结果**：状态→待确认
**驳回结果**：状态→已驳回
**驳回原因**：必填，<=500字
**通知**：通知申请人
```

问题：像状态流转配置表。

**metadata 字段关系**：

```yaml
pages:
  - id: PRD-PAGE-审核
    page_name: 入库审核页
    actions:
      - id: PRD-ACT-财务审核入库
        name: 财务审核入库
        fields:
          - field_id: PRD-FIELD-审核意见
            field_name: 审核意见
            usage: 编辑
          - field_id: PRD-FIELD-驳回原因
            field_name: 驳回原因
            usage: 编辑
            rule_refs:
              - PRD-RULE-驳回原因必填

rules:
  - id: PRD-RULE-入库财务审核
    name: 入库财务审核
    type: business
    field_refs: [PRD-FIELD-审核意见, PRD-FIELD-驳回原因]
    page_refs: [PRD-PAGE-审核]
    action_refs: [PRD-ACT-财务审核入库]
    description: 通过→待确认；驳回→已驳回+通知申请人
```

## 4. 导入/导出

**适用场景**：Excel 导入、模板下载、数据导出。

**目标写法**：

```markdown
点击"下载模板"按钮，系统生成标准物资导入模板 Excel 文件，浏览器自动下载。模板包含表头说明和必填字段标注。

点击"批量导入"按钮，打开导入弹窗，用户选择 Excel 文件后上传。系统校验文件格式（仅支持 .xlsx）、文件大小（不超过 10MB）、表头是否匹配模板。

校验通过后逐行解析：
- 必填字段为空的行标记为失败
- 枚举值不在允许范围内的行标记为失败
- 重复数据（按资产编码去重）标记为警告

解析完成后展示导入预览：成功 N 条、失败 N 条、警告 N 条。用户确认后提交，成功记录写入资产库，失败记录可下载错误报告。
```

**非目标写法**：

```markdown
支持批量导入标准物资，用户上传 Excel 文件后系统处理。
```

问题：缺少模板说明、文件校验、逐行解析规则、预览和错误报告。

**metadata 字段关系**：

```yaml
pages:
  - id: PRD-PAGE-导入
    page_name: 标准物资导入页
    actions:
      - id: PRD-ACT-批量导入标准物资
        name: 批量导入标准物资
        fields:
          - field_id: PRD-FIELD-资产编码
            field_name: 资产编码
            usage: 校验
```

## 5. 详情页

**适用场景**：查看某条记录的完整信息。

**目标写法**：

```markdown
点击列表中的"查看详情"操作，打开入库申请详情页。

详情页展示入库申请单编号、入库申请名称、申请服务区、所在区域、发起方式、申请人、目标服务区、入库状态、申请时间。下方物资明细区展示标准物资名称、规格型号、单位、数量、税后单价、税后价值。

入库状态为"待财务审核"时，页面顶部显示审核操作区。入库状态为"已驳回"时，页面显示驳回原因。入库状态为"已完成"时，页面显示确认人和确认时间。
```

**非目标写法**：

```markdown
详情页展示入库申请的全部信息。
```

问题：缺少具体字段、状态条件展示、操作区逻辑。

**metadata 字段关系**：

```yaml
pages:
  - id: PRD-PAGE-详情
    page_name: 入库申请详情页
    regions:
      - name: 状态区
        fields:
          - field_id: PRD-FIELD-入库状态
            field_name: 入库状态
            usage: 状态判断
```

## 6. 状态流转

**适用场景**：业务对象状态变化。

**目标写法**：

```markdown
入库申请的状态流转如下：

草稿 → 待确认 → 已确认 → 已完成
草稿 → 待财务审核 → 待确认 → 已确认 → 已完成
草稿 → 待财务审核 → 已驳回 → 待确认（重新提交）

状态流转规则：
- 草稿→待确认：全部明细税后价值均不大于 2000 元
- 草稿→待财务审核：任一明细税后价值大于 2000 元
- 待财务审核→待确认：财务审核通过
- 待财务审核→已驳回：财务审核驳回
- 待确认→已确认：服务区管理员确认入库
- 已确认→已完成：物资入库完成
```

**非目标写法**：

```markdown
入库申请有多种状态，按流程流转。
```

问题：缺少具体状态、流转条件、分支路径。

**metadata 字段关系**：

```yaml
rules:
  - id: PRD-RULE-入库状态流转
    name: 入库状态流转
    type: business
    trigger: 提交/审核/确认/完成
    logic: 状态机定义
    related_pages: [PRD-PAGE-列表, PRD-PAGE-详情]
```

## 7. 批量操作

**适用场景**：批量选择、批量删除、批量审批。

**目标写法**：

```markdown
列表区每行左侧显示复选框，支持全选当前页。选中记录后，操作区显示"批量删除"按钮。

点击"批量删除"后弹出确认弹窗，提示"确认删除选中的 N 条记录？删除后不可恢复"。确认后系统逐条删除，删除完成提示"成功删除 N 条"。

删除限制：
- 已被引用的标准物资不可删除，提示"该物资已被 N 条入库记录引用，无法删除"
- 部分删除成功时，提示"成功删除 M 条，N 条因被引用无法删除"
```

**非目标写法**：

```markdown
支持批量删除标准物资。
```

问题：缺少选择方式、确认弹窗、删除限制、部分成功处理。

**metadata 字段关系**：

```yaml
pages:
  - id: PRD-PAGE-列表
    page_name: 标准物资列表页
    actions:
      - id: PRD-ACT-批量删除
        name: 批量删除标准物资
        fields:
          - field_id: PRD-FIELD-删除结果
            field_name: 删除结果
            usage: 验收依据
        rule_refs:
          - PRD-RULE-批量删除引用检查

rules:
  - id: PRD-RULE-批量删除引用检查
    name: 批量删除引用检查
    type: validation
    field_refs: [PRD-FIELD-删除结果]
    page_refs: [PRD-PAGE-列表]
    action_refs: [PRD-ACT-批量删除]
    description: 已被引用的记录不可删除，部分成功时分别提示
```

## 8. 数据统计页

**适用场景**：仪表盘、汇总统计、图表展示。

**目标写法**：

```markdown
进入统计页面后，系统加载当月入库汇总数据。

顶部汇总区展示：本月入库申请总数、待处理数、已完成数、总入库金额。数据按当前登录用户的数据权限范围过滤。

下方图表区按入库状态分布展示饼图，按月度入库趋势展示折线图。图表支持切换时间范围（本月/本季度/本年）。

数据刷新：页面打开时加载一次，用户点击"刷新"按钮时重新加载。
```

**非目标写法**：

```markdown
统计页面展示入库相关数据汇总和图表。
```

问题：缺少具体指标、权限过滤、时间范围、刷新机制。

**metadata 字段关系**：

```yaml
pages:
  - id: PRD-PAGE-统计
    name: 入库统计页
    regions:
      - name: 汇总区
        fields: [申请总数, 待处理数, 已完成数, 总入库金额]
      - name: 图表区
        fields: [状态分布饼图, 月度趋势折线图]
    actions:
      - id: PRD-ACT-切换时间范围
        name: 切换时间范围
        trigger: 选择本月/本季度/本年
      - id: PRD-ACT-刷新数据
        name: 刷新数据
        trigger: 点击"刷新"按钮

rules:
  - id: PRD-RULE-统计数据权限过滤
    name: 统计数据权限过滤
    type: permission
    trigger: 页面加载
    logic: 数据按当前登录用户的数据权限范围过滤
    related_pages: [PRD-PAGE-统计]
```

## 9. 物资/对象选择器

**适用场景**：从弹窗中选择关联对象。

**目标写法**：

```markdown
点击"选择标准物资"按钮，打开物资选择器弹窗。

弹窗顶部为筛选区，支持按物资名称、物资编码、物资分类筛选。中部为物资列表，展示物资编码、物资名称、规格型号、单位、在库数量。底部为已选物资列表。

用户勾选物资后点击"确定"，弹窗关闭，选中物资回填到表单明细区。已选物资不可重复选择。

无匹配数据时，列表区显示"暂无标准物资"。选择器加载失败时，显示"加载失败，请重试"。
```

**非目标写法**：

```markdown
通过物资选择器选择标准物资。
```

问题：缺少筛选条件、列表字段、回填逻辑、重复选择处理、空状态和失败状态。

**metadata 字段关系**：

```yaml
pages:
  - id: PRD-PAGE-入库申请
    page_name: 入库申请页
    actions:
      - id: PRD-ACT-选择物资
        name: 物资选择器
        trigger: 点击"选择标准物资"按钮
        result: 弹窗打开，展示可选物资列表
      - id: PRD-ACT-确认选择
        name: 确认选择物资
        trigger: 勾选物资后点击"确定"
        result: 选中物资回填到表单明细区
        exception: 已选物资不可重复选择，无匹配数据显示空状态，加载失败显示重试提示
  - id: PRD-PAGE-选择器弹窗
    page_name: 物资选择器弹窗
    regions:
      - name: 物资列表
        fields:
          - field_id: PRD-FIELD-物资编码
            field_name: 物资编码
            usage: 筛选
          - field_id: PRD-FIELD-物资编码
            field_name: 物资编码
            usage: 展示
          - field_id: PRD-FIELD-在库数量
            field_name: 在库数量
            usage: 展示
```

## 10. 跨页面跳转

**适用场景**：从一个页面跳转到另一个页面。

**目标写法**：

```markdown
点击列表中的入库申请单编号，跳转到入库申请详情页。详情页顶部显示返回按钮，点击返回列表页并保持之前的筛选条件和页码。

从详情页点击"编辑"按钮，跳转到编辑页面。编辑完成后返回详情页，页面刷新为最新数据。

列表页、详情页、编辑页之间的跳转均保留面包屑导航，用户可点击面包屑快速返回上级页面。
```

**非目标写法**：

```markdown
点击编号可查看详情，详情页支持编辑。
```

问题：缺少返回逻辑、筛选条件保持、面包屑导航。

**metadata 字段关系**：

```yaml
pages:
  - id: PRD-PAGE-列表
    page_name: 入库申请列表页
    actions:
      - id: PRD-ACT-跳转详情
        name: 从列表跳转详情
        trigger: 点击申请单编号
        result: 打开详情页，保留面包屑导航
        navigation:
          to: PRD-PAGE-详情
          return: 返回列表页并保持筛选条件和页码
  - id: PRD-PAGE-详情
    page_name: 入库申请详情页
    actions:
      - id: PRD-ACT-跳转编辑
        name: 从详情跳转编辑
        trigger: 点击"编辑"按钮
        result: 打开编辑页
        navigation:
          to: PRD-PAGE-编辑
          return: 编辑完成后返回详情页，页面刷新为最新数据
  - id: PRD-PAGE-编辑
    page_name: 入库申请编辑页
    actions:
      - id: PRD-ACT-编辑完成返回
        name: 编辑完成返回详情
        trigger: 编辑完成提交
        result: 返回详情页
        navigation:
          to: PRD-PAGE-详情
```
