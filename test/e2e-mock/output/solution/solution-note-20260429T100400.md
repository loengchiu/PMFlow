> 生成时间：2026-04-29T10:04:00
> 基于：已确认 BRD + UC

## 1. 模块架构

### 模块清单

| 模块 | 说明 |
|------|------|
| 订单管理 | 采购订单的创建、编辑、提交 |
| 审批工作流 | 多级审批流转 |
| 审批记录 | 审批历史查看 |

## 2. 页面清单

| 页面 | 模块 | 类型 |
|------|------|------|
| 订单列表 | 订单管理 | 列表 |
| 订单详情 | 订单管理 | 详情 |
| 新建/编辑订单 | 订单管理 | 表单 |
| 我的审批 | 审批工作流 | 列表 |
| 审批详情 | 审批工作流 | 详情+操作 |
| 审批记录 | 审批记录 | 列表 |

## 3. 流程设计

### 主流程：采购订单审批

```
采购专员提交 → 部门经理审批 → 财务审批 → [金额>10万?] → 总经理审批 → 完成
                                                    ↓
                                                  完成
```

### 驳回流程

```
任意审批节点驳回 → 采购专员修改 → 重新从一级审批开始
```

## 4. 数据实体

| 实体 | 说明 |
|------|------|
| PurchaseOrder | 采购订单 |
| ApprovalRecord | 审批记录 |

## 5. 状态流转

```
DRAFT → PENDING_APPROVAL → DEPT_APPROVED → FINANCE_APPROVED → GM_APPROVED → COMPLETED
                  ↘ REJECTED（任意节点驳回）
```
