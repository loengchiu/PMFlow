# UC：采购订单审批流程

> 访谈时间：2026-04-29T10:02:00
> 访谈人：uc-interviewer

## 1. 用户角色

| 角色 | 标识 | 说明 |
|------|------|------|
| 采购专员 | Purchaser | 发起采购订单、修改被驳回订单 |
| 部门经理 | DeptManager | 一级审批人 |
| 财务审批人 | FinanceApprover | 二级审批人，审核预算 |
| 总经理 | GM | 终审人（大额>10万） |

## 2. 用户任务

### UC-001：采购专员发起采购订单
- 前置条件：已登录系统
- 主流程：填写订单信息→提交审批
- 后置条件：订单进入待审批状态

### UC-002：部门经理一级审批
- 前置条件：有待审批订单
- 主流程：查看订单→通过/驳回
- 后置条件：通过进入二级审批，驳回回到采购专员

### UC-003：财务审批人二级审批
- 前置条件：已通过一级审批
- 主流程：查看订单+预算→通过/驳回
- 后置条件：大额进入终审，小额完成审批

### UC-004：总经理终审
- 前置条件：订单金额>10万，已通过二级审批
- 主流程：查看订单+审批历史→通过/驳回
