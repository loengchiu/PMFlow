# BRD：采购订单审批流程

> 访谈时间：2026-04-29T10:00:00
> 访谈人：brd-interviewer

## 1. 业务背景

当前采购订单审批依赖邮件+Excel，审批周期长、状态不透明。财务部门提出需要线上化审批流程。

## 2. 业务目标

- 采购订单审批周期从平均5天缩短到2天
- 审批过程全程可追溯
- 支持多级审批（部门经理→财务→总经理）

## 3. 角色

| 角色 | 职责 |
|------|------|
| 采购专员 | 发起采购订单 |
| 部门经理 | 一级审批 |
| 财务审批人 | 二级审批（预算审核） |
| 总经理 | 终审（大额订单 >10万） |

## 4. 关键约束

- 订单金额>10万需总经理审批
- 审批驳回后采购专员可修改重新提交
- 所有审批操作留痕

## 5. 原始需求 vs 会后回答

### 原始需求
- 财务部门提出的采购审批线上化需求文档 v2.1

### 会后回答
- 采购专员：希望驳回后能有修改并重新提交的入口
- 财务审批人：需要看到预算占用情况
