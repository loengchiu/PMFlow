# Prototype：采购订单审批流程

> 生成时间：2026-04-29T10:07:00
> 基于：已确认 BRD + UC + Solution

## 1. 范围

本原型覆盖 solution 中定义的 6 个页面和 2 条流程。

## 2. 页面原型

### 2.1 订单列表（order_list）

**布局**：顶部筛选栏 + 表格 + 底部分页

**字段展示**：
| 字段 | 展示形式 |
|------|---------|
| 订单编号 | 文本链接 |
| 供应商 | 文本 |
| 金额 | 格式化数字 |
| 状态 | 标签 |
| 创建时间 | 日期时间 |
| 操作 | 按钮组 |

**筛选条件**：状态、创建日期范围、金额范围

### 2.2 订单详情（order_detail）

**布局**：信息卡片 + 审批时间线 + 操作区

### 2.3 新建/编辑订单（order_form）

**字段清单**：
| 字段 | 类型 | 必填 | 校验规则 |
|------|------|------|---------|
| 供应商 | 下拉选择 | 是 | - |
| 订单金额 | 数字输入 | 是 | >0 |
| 采购说明 | 文本域 | 否 | 最多500字 |
| 附件 | 文件上传 | 否 | PDF/图片，最大10MB |

### 2.4 我的审批（my_approvals）

**布局**：Tab切换（待审批/已审批）+ 列表

### 2.5 审批详情（approval_detail）

**布局**：订单信息摘要 + 审批表单（通过/驳回+意见）+ 历史审批记录

### 2.6 审批记录（approval_history）

**布局**：筛选 + 时间线列表

## 3. 流程原型

### 3.1 主流程：提交→多级审批

```
[采购专员] 新建订单 → 填写字段 → 提交
  → [部门经理] 审批列表 → 查看详情 → 通过/驳回
    → [财务审批人] 审批列表 → 查看+预算 → 通过/驳回
      → [金额>10万?]
        → 是：[总经理] 审批列表 → 查看 → 通过/驳回
        → 否：完成
```

### 3.2 驳回流程

```
[审批人] 驳回 + 填写意见
  → [采购专员] 订单列表(被驳回标记) → 编辑 → 重新提交
    → 从一级审批重新开始
```

## 4. 全局交互

- 所有审批操作（通过/驳回）需填写意见
- 列表支持分页和排序
- 状态变更时发送通知
